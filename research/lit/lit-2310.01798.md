## Takeaway
Without oracle labels, asking a model to critique and revise its own answer lowers accuracy, and multi-agent debate loses to plain self-consistency at equal numbers of responses. This is on reasoning tasks, not code, but it is the primary source for "same-model critic mostly does not help".

## Reported results
| Quantity | Value | Setting | Where |
|---|---|---|---|
| Claim | "LLMs struggle to self-correct their responses without external feedback" | | Abstract |
| With oracle labels | GPT-3.5 GSM8K 75.9 -> 84.3, CommonSenseQA 75.8 -> 89.7; GPT-4 HotpotQA 49.0 -> 59.0 | Table 2 | §3.1 |
| Intrinsic, no labels | GPT-3.5 CommonSenseQA 75.8 -> 38.1 (round 1), 41.8 (round 2); GSM8K 75.9 -> 75.1 -> 74.7; GPT-4 GSM8K 95.5 -> 91.5 -> 89.0 | Table 3 | §3.2 |

## Relevance
Part C and D. The oracle-label rows are the point: improvements arrive only when the correction is told which answers are wrong, i.e. when there is an external signal. A pure-text patch reviewer on the same model has none.

Transfers to our constraints: partly. GPT-3.5/4, reasoning tasks; no code.
