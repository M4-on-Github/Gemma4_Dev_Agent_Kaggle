One search-engine summary claimed a temperature effect (Llama 3.1 70B, 0.7 to 0.0, unique trajectories 4.2 to 2.2, accuracy +5.4); the abstract page reports no temperature experiment, so I treat that claim as unverified and do not use it.

## Takeaway
When the same agent repeats the same task, its action sequences differ, and how much they differ predicts failure. This is the one source I opened that measures run-to-run divergence of an agent's actions, and it puts the divergence early, at step 2.

## Relevance (mine)
- Shows that divergence of the first few actions between samples is the norm for API models at the temperature used, which is the opposite of the unanimous vote EXP-039 F2 fears, but it is for full action sequences of a multi-step ReAct agent, not for a letter from a short list.
- "Answer only when 3 runs agree" is the same shape as a margin gate: use agreement as a confidence signal and not as a decision. It needs a fallback for the disagreement case, which this paper does by abstaining.
- The 29.3% model-misranking rate by single runs is a noise number for how we read an 8-task screen: one draw from a spread of trajectories.
