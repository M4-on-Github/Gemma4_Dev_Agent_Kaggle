## Takeaway
Ensembles whose members differ in prompt (a different problem-solving approach and a persona chosen per question by the same model) beat same-prompt temperature-0.7 self-consistency at equal ensemble size in every row where both are reported, by large margins on planning and graph coloring. The paper does not run a control that varies temperature alone, so the gain is a joint effect of prompt diversity, per-question prompt generation and aggregation.

## Method
- DIV-SE: for each question the same model proposes approaches (b in [1,5] per query, repeated c = 100 times, the n most frequent kept, n in {3,5}) and personas; the ensemble is one call per approach-persona pair; majority vote (§2.1, footnote 1). IDIV-SE: all approaches inside one prompt (§2.2). Pairs selected on a validation set with fewer than 20 items (footnote 1).
- Ensemble size 5 for GSM8K and AQuA-RAT; 3 for planning, graph coloring and CommonsenseQA (§3). Self-consistency (SC) uses T = 0.7; all other methods use T = 0 (§3).
- Models: GPT-3.5 Turbo, GPT-4 (§3); LLaMA-2 70B, 8-bit, greedy (§4.2, App. B.1).

## Relevance (mine)
- This is the only source I opened that compares prompt-diverse and temperature-diverse members at equal ensemble size. It favours prompt diversity strongly on GPT-3.5 and GPT-4, and mildly on LLaMA-2 70B (Table 3: Div-Se 32.00 vs CoT 31.32 zero-shot, 39.9 vs 29.1 few-shot).
- Every member produces a chain of reasoning with a different method; a EXP-039 voter produces one letter after reading a fixed candidate list, so the "method" has no room to differ. Prompt diversity would have to enter as a different rule for choosing ("pick the smallest change", "pick the one that fixes the cause not the symptom") rather than a different solution path.
- Personas moved single-prompt accuracy by +4.33 and +8.27 on one dataset (Table 4); a different, small-model paper (lit-2604.03809) finds same-model persona agents still write near-identical rationales (cosine similarity 0.888), so persona alone is not guaranteed to give diversity.
- No model below 70B and no model after 2023 in the tables I opened.

## Ideas to test
- (mine) Claim: giving four groups of four voters four different one-line selection criteria (smallest edit; fixes the root cause; matches the failing symptom; least risk to other callers) raises the share of smoke-8 tasks where the 16 votes are not unanimous from the same-prompt arm's value by at least 2 tasks, without raising the malformed-vote rate. Needs a second arm; expressible as four instruction texts.
- (mine) Claim: winner differs from voter 1 in more tasks with criterion-diverse voters than with temperature-diverse voters at the same N. Falsified by D(criterion) <= D(temperature).

## Caveats
Reasoning and planning benchmarks, not repair; approach and persona are generated by the model per question, which a declarative tree cannot do without another agent call; validation set used to select pairs; no small model.
