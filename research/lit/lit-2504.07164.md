## Takeaway
With a 32B open model, an execution-based verifier (agent-written tests) and an execution-free verifier (trained model) each plateau around 43%, the hybrid reaches 51.0% at 26 candidates, against Pass@26 = 64.4%. The ablation that matters for us: the repo's own regression tests move the number more cheaply than model-written tests, and most model-written tests carry no signal.

## Method
- Agent: minimal scaffold on OpenHands; base models Qwen-2.5-Coder 7B, 14B, 32B (§3). Testing agent is Qwen-Coder-32B writing "a comprehensive test script containing M=10 diverse tests" (§4.1).
- TestScore = number of passing tests per patch; only patches with the highest regression-test score are eligible (§4.1, Eq. 1).
- Execution-free verifier: fine-tuned Qwen2.5-Coder-14B scoring patch plus trajectory (§4.1). Hybrid: execution-free score breaks ties inside the top-n by execution score (§4.3).

## Relevance
Under part A it says which signals work without hidden tests: repo regression tests (+4.5 points), model-written tests (small, mostly non-discriminative), a trained verifier (not available to us). Under part C it says an LLM judge reading the trajectory is biased by the agent's own stated reasoning.

Transfers to our constraints: partly. A separate trained 14B verifier and 26 full trajectories are impossible here; the regression-test finding and the "<20% of tests discriminate" rate transfer.
