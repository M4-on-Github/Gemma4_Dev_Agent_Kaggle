# leaderboard move: signal or noise?
run 1: 4/58 = 0.0690   Wilson 95% [0.027, 0.164]
run 2: 7/58 = 0.1207   Wilson 95% [0.060, 0.229]

Fisher exact two-sided p = 0.5281
pooled rate = 0.0948 (5.50 tasks of 58); binomial sd = 2.23 tasks
P(two IDENTICAL runs differ by >= 3 tasks) = 0.424
=> a 3-task move is NOT signal: identical configs reproduce it 42% of the time.
