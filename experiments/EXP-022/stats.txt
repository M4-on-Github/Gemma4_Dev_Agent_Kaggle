C. THE SIX-SUBMISSION DISPERSION TEST, re-done against the right null
====================================================================================================
scores [4, 7, 6, 8, 8, 7]: mean 6.667, sample variance 2.267, pooled p 40/348 = 0.11494
binomial expectation n p q = 5.900; X2 = 1.921 on 5 df; P(X2 <= observed) = 0.140 (low tail)

The six runs score the SAME 58 tasks. Conditional on that fixed task set the count is Poisson-binomial, whose variance is
sum p_i(1-p_i) = n mu (1-mu) (1 - rho), strictly BELOW the binomial n mu (1-mu) whenever tasks differ in difficulty.
So 'variance below binomial' is what ordinary difficulty heterogeneity predicts; it is not evidence of a deterministic core.

simulation: draw one 58-vector of task probabilities p_i ~ Beta(mean 0.1149, ICC rho), then six independent runs, s2 = sample variance of the six counts (20000 reps each).

  0.250   4.429      0.252            0.235

moment-matching the 'core + iid periphery' model to the six LB scores (mean 6.667, s2 2.267): c always-solved tasks, the other 58-c
solve independently with prob q per run, so mean = c + (58-c) q and variance = (58-c) q (1-q). Post-hoc, two moments, one free parameter:
   c    q       mean    variance   (observed variance 2.267)

  -> variance 2.267 is matched at c of roughly 4 to 5: about two thirds of a typical run's resolves would be 'core', one third lottery.
     This is the same split as the dev-48 overlap (6/11 and 6/9 repeat), obtained from independent data, and it is a consistency check only:
     the LB variance cannot distinguish a sharp core from smooth heterogeneity (section C simulation above).

comparing against a homogeneous binomial, which is the wrong null for a fixed task set.
